# Mon Rappel 4H

Application Android en français pour programmer un rappel à l'heure choisie, puis toutes les 4 heures après confirmation de la prise.

- Si la prise n'est pas confirmée, un rappel revient toutes les 15 minutes.
- Les rappels sont restaurés après redémarrage du téléphone.
- Notifications sonores via le canal Android.
- Le bouton « J'ai pris mon médicament » reporte le prochain rappel de 4 heures à partir de l'heure réelle de confirmation.

## Compilation
Le workflow GitHub Actions « Construire Mon Rappel 4H » produit un APK debug téléchargeable dans les artefacts du workflow.
